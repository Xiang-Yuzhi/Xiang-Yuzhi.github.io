个人简介

从武汉大学政治学、经济学与哲学专业(PPE)毕业后，我通过百贤亚洲研究院的全额奖学金来到香港科技大学攻读公共政策(MPP)硕士学位，同时也参与百贤亚洲研究院的亚洲未来领袖学者计划。

2019至2023年，我主要在武汉跟随不同的课题组进行基层治理与社会政策方面的深度科研。从2024年开始，我逐步转型，开始对产品经理、AI、供应链、投资等相关领域进行学习，并曾在亚马逊、阿里国际(LAZADA)相关部门实习。

目前，我仍在持续思考着怎样将过去看似“无关”的能力应用在不断变革的社会之中。
